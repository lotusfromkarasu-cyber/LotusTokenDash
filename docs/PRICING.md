# 当前价格与每周同步

LotusTokenDash 采用 OpenAI **当前 Standard 文本 Token 单价**估算费用。所有历史日期重新按最近同步的当前单价计算；它不是历史账单价格或订阅额度的折算。

官方与 custom 分组独立统计，但只要模型名匹配 OpenAI 模型，两者使用同一价格目录。缓存输入、未缓存输入和输出分别计费；推理 Token 已包含在输出中，不重复收费。长上下文部分使用官方对应的长上下文单价。

## 数据来源

后台直接 HTTPS 下载 [OpenAI 官方定价 Markdown](https://developers.openai.com/api/docs/pricing.md)，只读取 `Standard pricing data` 表和列名，不混入 Batch、Flex、Fast、Ultrafast 的价格。2026-10-03 核对的表包含 40 个模型，覆盖当前 Codex 菜单的全部 8 个模型。

价格是数据，不是程序中的单价常量：

- `source/app/src/data/openai-prices.json`：由官方页面生成的随包价格快照，首次断网启动也可用。
- 系统应用数据目录的 `openai-prices.json`：后台同步后的价格缓存，包含来源、抓取时间、核对时间、ETag 和模型价格。Windows 通常为 `%APPDATA%/com.lotus.tokendash/openai-prices.json`。
- `shared/pricing.ts`：按表头解析单价、提取长上下文阈值，匹配模型名。
- `server/pricingStore.ts`：加载、定时同步、验证和原子保存价格数据。

优先匹配完整模型名；没有独立价格的日期后缀回到基础模型，大小写统一。官方已公布单独价格的日期版本保留独立价格。`gpt-5.6` 的官方别名映射在价格数据中，指向 `gpt-5.6-sol`。没有公布价格的模型显示“未公布定价”，排除在金额估算外，Token 仍保留统计。

## 后台运行方式

不调用大模型，不需要 API key，不消耗 Codex 对话额度，也不启动浏览器或额外系统服务。现有桌面数据服务在启动时读取本地价格，并检查上次成功核对时间；到期就同步，否则设置计时器等待下一次到期。

成功核对后每 **7 天**请求一次。请求携带 `If-None-Match`；官方返回 `304` 时只更新核对时间，价格未变化时不重算费用。关闭期间到期，下一次打开补查。

下载失败或文档不能解析时保留上次核实的价格，次日重试。每次更新通过临时文件加重命名保存，避免半写入文件。连接支持系统／环境代理。

价格发生变化时，费用缓存按价格版本失效，后台计算线程接收相同的价格快照。已有 Token 索引保留，日报、项目、时段与会话金额、缓存节省金额和定价说明随当前价格更新。价格同步与界面的用量刷新间隔独立。

## 验证

自动检查覆盖标准／其他计费档位隔离、8 个模型当前单价、长上下文缓存节省、日期模型、未知模型、并发同步、7 天到期边界、ETag/304、重启后缓存、断网／损坏响应、价格变更后的费用缓存，以及官方与 custom 接口一致性。

费用估算使用 Standard 单价，不把 custom 服务商的实际账单或订阅配额等同于 API 费用。
