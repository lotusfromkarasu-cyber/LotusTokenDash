- HUD 用量与余量切换只改变官方配额比例和进度条，缺失值继续显示“—”；今日 Token 与缓存命中率仍属于当前选中的来源。

- 将拖动、悬停、按钮选择交给同一个控制器。异步命令按版本处理，过期的拖动和布局结果不覆盖新的选择；原生几何操作串行处理，调用窗口接口前释放状态锁。

- 类型检查和 194 项单元测试通过，包含悬停计时器、旧拖动结果、并发布局结果和尺寸上下限的 4 项回归测试。

# v0.1.3 拖动后悬停、HUD 控件与刷新间隔

- v0.1.2 的控制器会丢弃拖动期间的悬停事件，结束后强制收起；Windows 缺失新的进入事件时无法再展开。现保留最新悬停状态，拖动结束后处理，并通过松开后的移动事件和原生窗口位置检测恢复悬停。
- Windows 的移动回调不再阻塞前端拖动状态复位，由 `finish_drag` 检查实际鼠标释放；其他平台沿用其移动完成回调。窗口移动与按钮选择的版本顺序检查保留。
- 可见细条每 150 毫秒读取 [GetCursorPos](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-getcursorpos) 和窗口边界，仅在进入／离开或布局版本变化时发送事件。检测鼠标所在窗口，避免被其他窗口遮挡时误展开；HUD 状态、隐藏或鼠标按下期间不做悬停检测。不添加全局鼠标钩子或新依赖。
- 控件改为统一 SVG 图标，吸附／释放附带文字，尺寸控件单独分组并显示比例。英文界面截图与尺寸检查通过，中文切换用例保持通过。
- 自动刷新选择保存到本地并通过桌面事件同步到另一窗口。定时器按设置重新建立，手动模式停止定时器，手动刷新仍读取最新数据；修改刷新间隔不会销毁拖动控制器。
- 类型检查与 199 项单元测试通过，包含 5 项新拖动／悬停回归用例。17 项相关界面检查通过，其中两项使用可控时间验证实际请求频率、手动停止及同步后的 HUD 控件；另验证原有缓存刷新和会话详情行为。
- 原生验收增加真实渲染器／IPC 路径：在隐藏窗口中分别模拟 HUD 顶部吸附和细条移动，让移动回调保持未完成，验证拖动仍能结束，原生悬停事件能展开／收起界面，并实际增大原生窗口。测试不移动物理鼠标；最终真实拖动由用户验收。
- 源码 `be17c25758e3e442998982ba33ebe302f64f78ed` 的 [Windows 构建与原生验收](https://github.com/lotusfromkarasu-cyber/LotusTokenDash/actions/runs/37006884640)通过。本机免安装包及更新到 `K:/App/TOOL/LotusTokenDash` 的 v0.1.3 安装版分别通过两次冷启动和全部原生场景；旧版文件和用户设置保留。
