修复 Windows 打开分析窗口后出现黑窗、HUD 停止更新的问题。

- 分析窗口移出同步回调，在后台线程创建，避开 WebView2 死锁。
- 所有打开入口共用同一窗口，连续点击不会创建多个；关闭后再次打开恢复已有窗口，最小化后打开也会恢复。
- 前端启动先显示连接状态；服务连接失败时给出错误和重试按钮。
- 配额读取失败不再显示 LIVE；HUD 刷新同时更新今日使用量和官方配额。
- 保持 HUD、顶部吸附细条、来源分组与详细分析功能。

验证：190 项数据测试、5 项相关界面用例；打包后的 Windows 原生窗口连续启动两次，验证分析界面加载、8 次并发打开只创建一个分析窗口、关闭重开两次及 HUD 继续刷新。未使用 Computer Use。
