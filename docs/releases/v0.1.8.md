LotusTokenDash v0.1.8 在悬浮窗中加入 Agent 输出速率仪表，并在详细页面提供“使用分析 / Agent 速率”切换。

- 接入 Agent Speed 的本地计速核心，展示实时速率、今日峰值和平均值、各来源、活跃 Agent、最近五分钟曲线及每日／模型历史。生成中的速率可能为估算，完成后由实测修正。
- 速率汇总所有已检测的 Agent，支持 LotusTokenDash 已配置的多个 Codex 会话目录；原有 Codex 来源选择继续独立控制用量分析。
- 修复顶部吸附状态下选择 OpenAI 官方或 custom 时悬浮窗提前收起的问题；来源列表在窗口内显示，选择期间保持展开。
- 详细页面的配额进度条改为与悬浮窗一致的棕色和酒红色，并保留进度参考线。
- 同步 GPT-6.1 Terra 的 OpenAI Standard 价格。修复官方标准价格区块拆为两张表后同步失败的问题，升级时优先采用较新的随包价格。
- 保留 v0.1.7 的来源隔离、各模型小时明细、费用和缓存统计等功能。

速率信息读取本机日志，历史数据保存在 LotusTokenDash 自身数据目录。Windows x64 安装包和免安装包自带所需运行时，无需另外安装 .NET。Agent Speed 代码及许可证随源码和发行包提供。
